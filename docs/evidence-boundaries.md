# Evidence boundaries

The data included in this repository is synthetic. It demonstrates implementation and reasoning, not a client result.

Safe portfolio language:

- “Built a testable control tower that reconciles campaign and site events.”
- “Implemented explainable rules for funnel leaks, creative fatigue, and controlled retest decisions.”
- “Designed a cross-channel schema compatible with Meta, Google, TikTok, Shopify, and GA4-style exports.”

Avoid saying:

- “Reduced a client's CAC”;
- “Increased ROAS”;
- “Integrated a live Triple Whale account”;
- “Automatically optimized advertising budgets.”
